## IF YOU GET STUCK

### LinkedIn search returning 0 results?
- Try simpler search (just "Technical Recruiter")
- Remove location filter temporarily
- Use OR logic: "Tech Recruiter" OR "Technical Recruiter"

### Can't find company size filter?
- Try using search box instead
- Search "company:\"[Company Name]\"" in search bar
- Filters appear on left sidebar after search

### Google Form not saving responses?
- Check you clicked "Submit" (not just filled form)
- Form should show "response recorded"
- Refresh page to verify

### Not sure if message sounds good?
- Re-read it out loud
- Does it sound like you're talking to a friend?
- Cut anything that sounds "corporate"
- Keep it casual and real

### Took longer than expected?
- Don't rush quality for speed
- Better to send 3 great messages than 5 rushed ones
- Can always send second batch later
