🚀 DEPLOYMENT (10 MINUTES - Choose your API):

   STEP 1: Add API Key (5 min)
   ──────────────────────────────
   Option A (Claude - Recommended):
      1. Get key: https://console.anthropic.com/api_keys
      2. Create .env.local: CLAUDE_API_KEY=sk-ant-...
      3. Test: npm run dev

   Option B (Manifest):
      1. Get key: https://manifest.conversationmine.ai/api/keys
      2. Create .env.local: MANIFEST_API_KEY=mk-...
      3. Test: npm run dev

   STEP 2: Push to GitHub (2 min)
   ──────────────────────────────
   $ cd /Users/iamkrisk/Documents/imskrisk/imKrisK-widget
   $ git push origin main

   STEP 3: Deploy to Cloudflare Pages (3 min)
   ──────────────────────────────────────────
   1. Go to: https://dash.cloudflare.com/
   2. Click: Workers & Pages → Pages → Connect to Git
   3. Select: imKrisK/imKrisK-widget repository
   4. Configure build:
      - Build command: npm run build
      - Output directory: .next/standalone/public
      - Environment variables: Add CLAUDE_API_KEY or MANIFEST_API_KEY
   5. Click: Save and Deploy ✅
