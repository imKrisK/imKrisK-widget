# Phase 1: Resume Naming Convention Guide

## Why This Matters (LinkedIn Insight)

From recruiter Shayna Cavanaugh's post:
> "When you save your resume, include your name and position title. Make it easy for the hiring team to name it something simple and identifying."

**Translation:** Recruiters receive HUNDREDS of resumes. A well-named resume:
- ✅ Shows attention to detail
- ✅ Makes their job easier
- ✅ Signals professionalism
- ✅ Increases chance of being found/remembered
- ❌ Avoid: "Resume.pdf", "Resume (2).pdf", "Resume-FINAL-v3.pdf"

---

## Your Resume Naming Strategy for Phase 1

### **Primary Filename** (Use this when sending)
```
Kristoffer-Kelly-Operations-Manager.pdf
```

**Why this format:**
- Clear (name + title)
- Professional (hyphens, no spaces)
- SEO-friendly for recruiter's file search
- Memorable (includes both name and role)

### **Alternative Filenames** (Context-specific)

**For tech/engineering recruiters:**
```
Kristoffer-Kelly-Technical-Operations.pdf
```

**For leadership/management roles:**
```
Kristoffer-Kelly-Operations-Leader.pdf
```

**For legal/compliance specialists:**
```
Kristoffer-Kelly-Compliance-Operations.pdf
```

**For legal operations specifically:**
```
Kristoffer-Kelly-Legal-Operations-Manager.pdf
```

## Where to Use This in Phase 1

### **Strategy 1: Direct LinkedIn Messages**
When you message a recruiter:
- Mention your resume is attached
- If they ask: "I've named it `Kristoffer-Kelly-Operations-Manager.pdf` for easy filing"
- Shows intentionality

### **Strategy 2: Google Form Submission**
In Phase 1 feedback form:
- Ask: "What's your filename when you save resumes?"
- Include note: "Mine is `Kristoffer-Kelly-Operations-Manager.pdf`"
- Reinforces attention to detail

### **Strategy 3: Email Introductions**
When emailing recruiters:
```
Hi [Name],

I'm Kristoffer Kelly, Operations Manager with 10+ years in business 
leadership and process optimization. My resume is attached 
(Kristoffer-Kelly-Operations-Manager.pdf).

[Reason for reaching out]

Best,
Kristoffer
```

## Resume Content Checklist

**Your resume should highlight:**

✅ **Title** (clear positioning)
   - Technical Operations Manager
   - Operations Manager | Process Systems | Legal & Compliance

✅ **Top Achievement** (72→5h)
   - "Compressed 72-hour manual process into 5-hour automated workflow"
   - "Reduced cycle time by 93% while improving accuracy"

✅ **Scale** (15+ team)
   - "Supervised 15+ staff across regional locations"
   - "Maintained 99%+ accuracy on high-volume compliance work"

✅ **Proof of Capability** (ACIL)
   - "Built and shipped ACIL on VS Code Marketplace"
   - "Prevented $111 API cost overruns through token budget validation"

✅ **Education**
   - Software Engineering Professional Certification (UNLV/Institute of Data, 2025)
   - College-level coursework
   - **Don't claim**: Bachelor's, Master's, traditional degree

✅ **Contact/Links**
   - GitHub (if public projects)
   - **Widget URL** (imkrisk-widget-production.up.railway.app)
   - LinkedIn
   - Email
